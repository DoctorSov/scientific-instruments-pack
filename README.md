# scientific-instruments-pack

Ресурс-пак для мода **Scientific Instruments** (Fabric 1.21.10). Отдельный репозиторий, потому
что сам мод лежит в закрытом, а пак должен скачиваться по анонимной ссылке: Minecraft качает
`resource-pack=` без всякой авторизации, и ссылка из приватного репозитория отдаёт ему 404.

## Что здесь лежит

`RPVL4.5.5.zip` — тот самый пак, который сервер объявляет в `server.properties`. Внутри он
называется `scikinstruments-pack.zip`; имя файла в релизе версионное, чтобы разные сборки нельзя
было перепутать.

Содержимое: приборы мода, а также ресурсы `KSEPSP`, `DINOBRIKS RUM` и `VLP`, слитые в один пак.
`pack_format` 69, 4 177 записей.

## Как этим пользуются

Сервер объявляет прямую ссылку на ассет релиза:

```
resource-pack=https://github.com/DoctorSov/scientific-instruments-pack/releases/download/v4.5.5/RPVL4.5.5.zip
resource-pack-sha1=<sha1 файла>
```

Клиенту ничего не нужно: пак скачается сам при входе. Fabric API и мод ставятся отдельно.

## Почему sha1 обязателен

Если хеш не совпадёт с файлом, ванильный клиент скачает пак и **молча его отбросит** — приборы
отрисуются самородками, и в логе сервера не будет ни строчки. Поэтому при каждом обновлении пака
хеш в `server.properties` обновляется вместе с ним.

## Обновление

1. Собрать пак вместе с модом (он пишется при старте сервера).
2. Залить новым именем `RPVL<версия>.zip` в новый релиз этого репозитория.
3. Взять SHA-1 загруженного файла и вписать в `server.properties`.
4. Проверить, что клиент получит рабочий пак, а не страницу: скачать по объявленному адресу и
   сверить байты, `Content-Type` и SHA-1.
